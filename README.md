# Centre documentaire

Menu carrousel responsive en HTML, CSS et JavaScript.

## Catégories

- Plannings
- Docs adhérents
- Docs Coachs
- Procédures

## Utilisation

Ouvrir `index.html` dans un navigateur moderne. Le carrousel prend en charge les boutons précédent/suivant, les points indicateurs, les touches fléchées et le glissement tactile.
